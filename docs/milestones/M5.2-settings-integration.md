# M5.2 — Settings Integration

**Goal:** wire the settings from M5.1 to the actual behaviour of the application. The changes take effect immediately, with no restart.

**Estimate:** 0.5 of a working day
**Dependencies:** M5.1 finished (SettingsStore exists)
**Definition of done:** changing the language / overlay / insertion method in the settings affects the very next transcription

## Tasks

### 1. The transcription language (settings.language)

**File:** `SayVoice/Transcription/TranscriptionEngine.swift`

Right now `WhisperContext.transcribe()` always passes `language = -1` (auto). What is needed:
- `TranscriptionEngine.transcribe()` takes a `language: String` parameter
- It passes it to `WhisperTranscriber` → `whisper_bridge_transcribe` → `params.language`

**File:** `Packages/CWhisper/Sources/CWhisper/whisper_bridge.cpp`
- Now: `params.language = "auto"` (hard-coded)
- Needed: use `bridge_params.language` from `SayVoiceWhisperParams`

**File:** `Packages/CWhisper/Sources/CWhisper/include/whisper_bridge.h`
- Add `const char* language` to `SayVoiceWhisperParams`

**AppCoordinator.swift:**
```swift
// In handleKeyUp():
let lang = settingsStore.language  // "auto", "ru", "en"
let text = try await transcriptionEngine.transcribe(samples, language: lang)
```

### 2. The overlay toggle (settings.overlayEnabled)

**File:** `SayVoice/App/AppCoordinator.swift`

```swift
// In handleStateChange():
case .recording:
    if settingsStore.overlayEnabled {
        overlayController?.show(message: "Recording…", isRecording: true)
    }
case .transcribing:
    if settingsStore.overlayEnabled {
        overlayController?.show(message: "Transcribing…")
    }

// In handleKeyUp() — always show the result (even with no overlay during the recording):
if settingsStore.overlayEnabled {
    overlayController?.show(message: text)
    overlayController?.dismiss(after: 2.0)
}
```

### 3. The insertion method (settings.pasteMethod)

**File:** `SayVoice/TextInjection/TextInjector.swift`

```swift
// Instead of the automatic AX → fallback:
func inject(text: String, method: String = "auto") {
    switch method {
    case "ax":
        // AX only, no fallback
        let _ = axInjector.inject(text: textWithSpace, targetPID: pid)
    case "pasteboard":
        // The pasteboard only, no AX
        pasteboardInjector.inject(text: textWithSpace)
    default: // "auto"
        // The current logic: AX → the pasteboard fallback
    }
}
```

**AppCoordinator.swift:**
```swift
textInjector.inject(text: text, method: settingsStore.pasteMethod)
```

### 4. The model (settings.modelSize)

**File:** `SayVoice/Transcription/TranscriptionEngine.swift`

Right now `modelSize` is fixed in init(). When the model is changed in the settings we need to:
1. Drop the loaded one: `transcriber = nil`
2. Load the new model on the next `ensureLoaded()`

```swift
func switchModel(to size: ModelManager.ModelSize) {
    transcriber = nil  // The next transcribe() reloads it
}
```

**AppCoordinator** watches `settingsStore.modelSize` for changes and calls `switchModel()`.
