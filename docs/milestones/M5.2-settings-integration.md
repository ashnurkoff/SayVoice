## Задачи

### 1. Язык транскрипции (settings.language)

**Файл:** `SayVoice/Transcription/TranscriptionEngine.swift`

Сейчас `WhisperContext.transcribe()` всегда передаёт `language = -1` (auto). Нужно:
- `TranscriptionEngine.transcribe()` принимает `language: String` параметр
- Передаёт в `WhisperTranscriber` → `whisper_bridge_transcribe` → `params.language`

**Файл:** `Packages/CWhisper/Sources/CWhisper/whisper_bridge.cpp`
- Сейчас: `params.language = "auto"` (хардкод)
- Нужно: использовать `bridge_params.language` из `SayVoiceWhisperParams`

**Файл:** `Packages/CWhisper/Sources/CWhisper/include/whisper_bridge.h`
- Добавить `const char* language` в `SayVoiceWhisperParams`

**AppCoordinator.swift:**
```swift
// В handleKeyUp():
let lang = settingsStore.language  // "auto", "ru", "en"
let text = try await transcriptionEngine.transcribe(samples, language: lang)
```

### 2. Overlay toggle (settings.overlayEnabled)

**Файл:** `SayVoice/App/AppCoordinator.swift`

```swift
// В handleStateChange():
case .recording:
    if settingsStore.overlayEnabled {
        overlayController?.show(message: "Запись...", isRecording: true)
    }
case .transcribing:
    if settingsStore.overlayEnabled {
        overlayController?.show(message: "Транскрибирую...")
    }

// В handleKeyUp() — показывать результат всегда (даже без overlay во время записи):
if settingsStore.overlayEnabled {
    overlayController?.show(message: text)
    overlayController?.dismiss(after: 2.0)
}
```

### 3. Метод вставки (settings.pasteMethod)

**Файл:** `SayVoice/TextInjection/TextInjector.swift`

```swift
// Вместо автоматического AX → fallback:
func inject(text: String, method: String = "auto") {
    switch method {
    case "ax":
        // Только AX, без fallback
        let _ = axInjector.inject(text: textWithSpace, targetPID: pid)
    case "pasteboard":
        // Только pasteboard, без AX
        pasteboardInjector.inject(text: textWithSpace)
    default: // "auto"
        // Текущая логика: AX → pasteboard fallback
    }
}
```

**AppCoordinator.swift:**
```swift
textInjector.inject(text: text, method: settingsStore.pasteMethod)
```

### 4. Модель (settings.modelSize)

**Файл:** `SayVoice/Transcription/TranscriptionEngine.swift`

Сейчас `modelSize` фиксирован в init(). При смене модели в настройках нужно:
1. Сбросить загруженный `transcriber = nil`
2. При следующем `ensureLoaded()` загрузить новую модель

```swift
func switchModel(to size: ModelManager.ModelSize) {
    transcriber = nil  // Следующий transcribe() перезагрузит
}
```

**AppCoordinator** слушает изменение `settingsStore.modelSize` и вызывает `switchModel()`.
