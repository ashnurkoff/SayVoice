# M5.3 — Sound Feedback

**Цель:** Звуковая обратная связь при начале и конце записи. Управляется toggle в настройках.

**Оценка:** 0.5 рабочего дня
**Зависимости:** M5.1 завершён (settings.soundFeedback)
**Критерий готовности:** Tink при начале записи, Pop при завершении, тихо когда выключено

## Задачи

### 1. Звуки в AppCoordinator

**Файл:** `SayVoice/App/AppCoordinator.swift`

Используем системные звуки macOS (не нужны свои аудиофайлы):

```swift
import AppKit

private func playStartSound() {
    guard settingsStore.soundFeedback else { return }
    NSSound(named: "Tink")?.play()
}

private func playEndSound() {
    guard settingsStore.soundFeedback else { return }
    NSSound(named: "Pop")?.play()
}

private func playErrorSound() {
    guard settingsStore.soundFeedback else { return }
    NSSound(named: "Basso")?.play()
}
```

### 2. Подключение к state machine

**В handleStateChange():**

```swift
case .recording:
    playStartSound()
    // ... overlay

case .idle:
    if old == .injecting {
        playEndSound()   // Успешная транскрипция + вставка
    }
    overlayController?.dismiss()

case .error(let err):
    if err != .recordingTooShort {
        playErrorSound()
    }
    // ... overlay
```

**Логика звуков:**

| Переход | Звук | Когда |
|---|---|---|
| idle → recording | Tink | Начало записи |
| injecting → idle | Pop | Успешная вставка |
| * → error | Basso | Ошибка (кроме recordingTooShort) |
| recording → idle (short) | — | Тихо |

### 3. Стандартные системные звуки macOS

Звуки расположены в `/System/Library/Sounds/`:
- `Tink` — тихий клик (старт записи)
- `Pop` — мягкий хлопок (завершение)
- `Basso` — низкий звук (ошибка)
- `Purr` — мурчание (альтернатива для успеха)

`NSSound(named:)` ищет по имени без расширения, находит автоматически.
