# M5.3 — Sound Feedback

**Goal:** sound feedback when the recording starts and ends. Controlled by a toggle in the settings.

**Estimate:** 0.5 of a working day
**Dependencies:** M5.1 finished (settings.soundFeedback)
**Definition of done:** Tink when the recording starts, Pop when it finishes, silence when it is switched off

---

## Tasks

### 1. The sounds in AppCoordinator

**File:** `SayVoice/App/AppCoordinator.swift`

The macOS system sounds are used (no audio files of our own are needed):

```swift
import AppKit

private func playStartSound() {
    guard settingsStore.soundFeedback else { return }
    NSSound(named: "Tink")?.play()
}

private func playEndSound() {
    guard settingsStore.soundFeedback else { return }
    NSSound(named: "Pop")?.play()
}

private func playErrorSound() {
    guard settingsStore.soundFeedback else { return }
    NSSound(named: "Basso")?.play()
}
```

### 2. Wiring them into the state machine

**In handleStateChange():**

```swift
case .recording:
    playStartSound()
    // ... overlay

case .idle:
    if old == .injecting {
        playEndSound()   // A successful transcription + insertion
    }
    overlayController?.dismiss()

case .error(let err):
    if err != .recordingTooShort {
        playErrorSound()
    }
    // ... overlay
```

**The logic of the sounds:**

| Transition | Sound | When |
|---|---|---|
| idle → recording | Tink | The recording starts |
| injecting → idle | Pop | A successful insertion |
| * → error | Basso | An error (except recordingTooShort) |
| recording → idle (short) | — | Silence |

### 3. The standard macOS system sounds

The sounds live in `/System/Library/Sounds/`:
- `Tink` — a quiet click (the recording starts)
- `Pop` — a soft pop (it finishes)
- `Basso` — a low sound (an error)
- `Purr` — a purr (an alternative for success)

`NSSound(named:)` looks the sound up by name without an extension and finds it automatically.

## The M5.3 definition of done

- [x] The recording starts → the Tink sound
- [x] A successful insertion → the Pop sound
- [x] A transcription error → the Basso sound
- [x] A short recording (<0.3 sec) → silence, no sound
- [x] The "Sound feedback" toggle OFF → every sound is off
- [x] The toggle ON → the sounds work again (with no restart)
- [x] 0 errors, 0 warnings
