# SayVoice

Нативное macOS-приложение для голосовой транскрипции на устройстве. Зажмите хоткей, скажите фразу, отпустите — текст моментально появится в активном поле. Никаких облаков, полная приватность.

---

## Ключевые возможности v1.0

- **Push-to-talk** — удерживайте Right Option, говорите, отпустите
- **Полностью локально** — whisper.cpp с Metal-ускорением на Apple Silicon, интернет не нужен
- **Работает везде** — глобальный хоткей из любого приложения
- **Умный инжект текста** — вставляет в позицию каретки через Accessibility API, fallback на буфер обмена
- **Menu bar приложение** — нет иконки в Dock, не мешает рабочему столу
- **Русский + Английский** — авто-определение языка, без настроек
- **История транскрипций** — последние 500 записей локально

---

## Как это работает

```
[Зажать Right Option]
        │
        ▼
  Запись микрофона
  (AVAudioEngine → 16kHz mono Float32)
        │
[Отпустить Right Option]
        │
        ▼
  Локальная транскрипция
  (whisper.cpp + ggml-small модель, ~2-3 сек на M-серия)
        │
        ▼
  Инжект текста в активное поле
  (AXUIElement → или буфер обмена + Cmd+V)
        │
        ▼
  Overlay показывает результат 1.5 сек
```

## Системные требования

| Параметр | Минимум | Рекомендуется |
|---|---|---|
| macOS | 14.0 (Sonoma) | 15.0+ |
| Процессор | Intel Core i5 | Apple Silicon M1+ |
| RAM | 4 GB | 8 GB+ |
| Место на диске | 600 MB | 1 GB (под модели) |
| Разрешения | Микрофон + Accessibility | — |

> **Важно:** Приложение не распространяется через Mac App Store — требует отключённый App Sandbox для работы CGEventTap и Accessibility API.

## Конкуренты (для референса)

- **Superwhisper** — ближайший аналог, платный ($8/мес), облачный по умолчанию
- **AquaVoice** — фокус на continuous dictation, не push-to-talk
- **Spokenly** — веб-ориентированный, менее системный
